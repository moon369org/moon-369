IS IT ON MOON?

Drop a photo, a video, a contract, anything. Moon tells you if it was registered, by whom and when. For photos it also finds copies that were cropped, resized or recompressed. Your file never leaves your device.

HOW IT WORKS

01 · FINGERPRINT

Your browser computes the file's SHA-256. Change one byte and it changes completely, so a match means the very same file.

02 · LOOK-ALIKE HASH

For photos, it also computes a 64-bit picture hash that stays close when the image is resized, recompressed or lightly edited.

03 · LOOKUP

Moon returns every registration: the Moonmark, who registered it, and a link to the signed proof. The earliest is usually the original.

Who registered it: when a company signs with an API key, Moon vouches for the company name. Anything they add, like the photographer's name, is shown as they stated it. Files signed without a key show as anonymous.

PUT IT ON YOUR SITE

One script. A badge next to any image or file you have registered, or this same checker on your own page.

<script src="https://moon369.org/embed/moon.js" defer></script>

<!-- A badge: shows who registered the file and when -->
<moon-badge sha256="9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08"></moon-badge>

<!-- A drop zone to check any file -->
<moon-check></moon-check>

The API behind it: GET /v1/lookup/{sha256} and POST /v1/lookup/similar.
