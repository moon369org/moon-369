02

HOW IT WORKS

The lock never asks the internet whether to open. Everything it needs to decide is in the pass, signed by Moon, plus the guest's phone and the lock's clock.

ONE INVITE, ONE PHONE

The host books a stay and sends the guest an invite that works once. The guest's phone makes its own key and keeps the private half locked.

MOON SIGNS THE PASS

Moon signs the door, the stay, the phone's key and a time window. It's renewed each day while the phone is online, so a cancelled stay stops working within a day.

A NEW CODE EVERY 30 SECONDS

The QR carries the pass and the phone's signature on the current 30 seconds. The lock checks Moon's signature, the window and the phone's code, all offline.

A PIN FOR A DEAD PHONE

Each stay also gets a 10-digit backup PIN. The lock works it out itself from the dates and a secret it shares with Moon. Every opening is logged and signed.

03

WHAT STOPS WHAT

No internet at the cabinThe lock never needed it. It checks signatures with Moon's public key and its own clock.
A screenshotStale within a minute, and each code opens the door once.
A forwarded inviteIt works once. The pass lives on the first phone that opened it.
Arriving early or staying lateThe pass and the PIN only work between check-in and check-out.
A cancelled bookingThe lock refuses it at its next sync, and the pass can't renew past the next day.
A dead phoneThe backup PIN works the same window, offline.
04

BUILD YOUR OWN

Stays is an open API, and the lock's check is a few lines of standard cryptography that run anywhere: a browser, a phone by the door, a small board wired to a lock. Use Moon's pages, or build your own around them.

const [door, stay, nb, na, pub, kid, moonSig, w, sig] = payload.split('#')[1].split('.');
const moon = await importEd25519(MOON_KEYS[kid]);
const pass = ['moon-stay-pass/1', door, stay, pub, nb, na].join('\n');
if (!await verify(moon, moonSig, pass)) return 'NOT SIGNED BY MOON';
const now = Date.now() / 1000;
if (now < nb || now > na) return 'OUTSIDE THE STAY';
if (Math.abs(Math.floor(now / 30) - w) > 1) return 'OLD CODE';
const phone = await importP256(pub);
const code = `moon-stay-code/1|${door}|${stay}|${w}`;
return await verify(phone, sig, code) ? 'OPEN' : 'WRONG PHONE';
