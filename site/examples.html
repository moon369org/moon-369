START WITH ONE CALL

Everything above is built on calls like this one. Only the fingerprint is sent, never the thing itself.

sign.jsPOST /v1/sign
// Prove when anything existed. Works in any browser or in Node 18+.
const bytes = new TextEncoder().encode("The thing I want to prove");
const hash = await crypto.subtle.digest("SHA-256", bytes);
const sha256 = [...new Uint8Array(hash)]
  .map(b => b.toString(16).padStart(2, "0")).join("");

const r = await fetch("https://api.moon369.org/v1/sign", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ sha256 })
}).then(r => r.json());

console.log(r.receipt.moonmark);   // the moment, signed by Moon
// Keep r.receipt. Anyone can check it at moon369.org/verify,
// or with POST /v1/verify, or offline with Moon's public key.
