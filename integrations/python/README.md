# Python: sign generated output

`moon_sign.py` is one file, standard library only. Drop it next to your code.

```python
from moon_sign import sign_file
res = sign_file("out.png", label="AI-generated by flux-dev")   # writes out.png.moonmark.json
print(res["signed_url"])                                        # the proof link
```

Use it right after any generator saves a file: OpenAI, Flux, Stability, Replicate, Midjourney exports or your own
model. `example_openai_images.py` shows it with the OpenAI SDK. From the command line: `python moon_sign.py *.png`.

Only fingerprints are sent. Label AI output honestly ("AI-generated by …"): Moon proves when something was
registered and by whom, not how it was made. `MOON_KEY` registers under your verified name and lifts the rate limit.
Anyone can check a file at [moon369.org/verify](https://moon369.org/verify).
