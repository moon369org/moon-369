# Moon for Automatic1111 and Forge

Signs every image the web UI saves, the moment it's saved. Each image gets `<image>.moonmark.json` next to it and the
proof link is printed in the console. The label records the model: "AI-generated by <model>: <file>".

## Install

Copy this folder into `stable-diffusion-webui/extensions/` as `moon-sign` and restart the web UI. No extra packages.

Set `MOON_KEY` (free at [moon369.org/api#key](https://moon369.org/api#key)) to register images under your verified
name and lift the rate limit. Set `MOON_SIGN=0` to pause signing.

Note: this signs the file as saved. If you set the web UI to save images *and* a separate grid, each file is signed on
its own. Anyone can check a file at [moon369.org/verify](https://moon369.org/verify).
