# Moon for ComfyUI

A **Save Image (signed on Moon)** node. Use it in place of Save Image: every image is saved as usual, then signed on
Moon, with its receipt written next to it as `<name>.png.moonmark.json` and the proof link printed in the console.

## Install

Copy this folder into `ComfyUI/custom_nodes/` as `moon-sign`, then restart ComfyUI. No extra packages.

```sh
cd ComfyUI/custom_nodes
git clone --depth 1 https://github.com/moon369org/moon-369 moon-369-src && mv moon-369-src/integrations/comfyui moon-sign && rm -rf moon-369-src
```

Set `MOON_KEY` (free at [moon369.org/api#key](https://moon369.org/api#key)) before starting ComfyUI to register images
under your verified name and lift the rate limit. The node's `generator` field is recorded in each label as
"AI-generated by …".

Only the file's SHA-256 is sent. Anyone can drop the PNG on [moon369.org/verify](https://moon369.org/verify) to see
when it was registered. Change one pixel and it no longer matches.
